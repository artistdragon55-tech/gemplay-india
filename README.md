# GemPlay India (Prototype)

A mobile-first, single-page browser prototype inspired by modern gem-game lobby layouts. This is a **non-commercial simulation**.

## Features
- Responsive mobile UI
- Simulated demo wallet display (points are not money)
- Daily bonus (one per page session)
- Gem reveal mini-game
- Spin animation demo
- Recent activity/profile sections

## Run locally
Open `index.html` in any modern browser.

## Publish on GitHub Pages
1. Create a GitHub repository (for example `gemplay-india-demo`).
2. Upload `index.html` and `README.md` to the repository root.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for the Pages deployment; GitHub will show the public URL.

## Limitations
No authentication, server, real wallet, deposit, withdrawal, betting, cash prizes, or account data storage. The displayed points are simulated and have no monetary value.
